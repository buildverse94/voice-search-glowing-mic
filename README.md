# 🎙️ Voice Search Mic with JavaScript

A modern and interactive **Voice Search Application** built using HTML, CSS, and JavaScript. This project uses the **Web Speech API** to recognize voice input and display the recognized speech in a search field, with a glowing microphone UI and smooth visual effects.

## ✨ Features

- 🎤 **Voice Recognition** — Convert spoken words into text.
- 🔊 **Interactive Microphone** — Start voice recognition with a mic button.
- 💡 **Glowing UI Effects** — Modern microphone design with visual effects.
- 📝 **Live Speech Results** — Display recognized speech in the search input.
- ⏹️ **Start and Stop Recognition** — Control the voice recognition process.
- ⚠️ **Error Handling** — Handle recognition errors and unavailable microphone access.
- 📱 **Responsive Design** — A clean interface for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** — Application structure
- **CSS3** — Styling, glowing effects, and animations
- **JavaScript** — Voice recognition and interactive functionality
- **Web Speech API** — Speech-to-text recognition

## 🎙️ How to Use

1. Open the application in a supported browser.
2. Allow microphone access when prompted.
3. Click the microphone button to start voice recognition.
4. Speak clearly into your microphone.
5. View the recognized text in the search field.
6. Stop recognition when you're finished.

## 🌐 Browser Compatibility

The Web Speech API is not supported consistently across all browsers. Use a browser that supports `SpeechRecognition` or `webkitSpeechRecognition`, and allow microphone access when prompted.

Microphone access and speech recognition may require HTTPS or localhost, depending on the browser.
